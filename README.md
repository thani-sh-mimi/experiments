# Experiments

One small SDLC problem a day: a hypothesis with a number in it, a harness that measures it, a verdict. Bun scripts, synthetic input, no services.

| #   | Experiment                                                               | Question                                                                     | Verdict                                                                                                                          |
| --- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 001 | [test-file-overhead](experiments/001-test-file-overhead)                 | What does each extra test file cost `bun test`?                              | Validated: 0.18 ms/file, 6 ms fixed                                                                                              |
| 002 | [json-vs-sqlite-cache](experiments/002-json-vs-sqlite-cache)             | At what size does a JSON cache file stop being fine?                         | Partial: crossover ~5k entries, parse dominates                                                                                  |
| 003 | [pre-commit-format-budget](experiments/003-pre-commit-format-budget)     | Where does `prettier --check .` break a one-second commit budget?            | Partial: 128 files; staged-only flat at 300 ms                                                                                   |
| 004 | [incremental-type-check](experiments/004-incremental-type-check)         | What does `tsc --incremental` save on 300 vs 1,000 modules?                  | Partial: 2.3× at 300, 8× at 1,000; edit mid-graph saves nothing                                                                  |
| 005 | [squash-vs-blame](experiments/005-squash-vs-blame)                       | What a squash merge costs `git blame` on a 5k-commit history                 | Partial: 6.6× faster blame, one-line blame unchanged, 64% of lines coarsened                                                     |
| 006 | [barrel-import-cost](experiments/006-barrel-import-cost)                 | What a re-export barrel costs a build                                        | Validated: 26 ms at 1,000 re-exports, ~0.03 ms/line; nesting cheaper than width                                                  |
| 007 | [shallow-clone-cost](experiments/007-shallow-clone-cost)                 | How much `--depth 1` saves, and from what history size                       | Validated: flat 40 ms vs 0.12 ms/commit; 18% saved at 100 commits, 92% at 4,000                                                  |
| 008 | [file-size-parse-cost](experiments/008-file-size-parse-cost)             | Does cutting the same bytes into smaller files cost parse time?              | Partial: 2.2× more at 834 files, but an edit is still under 2 ms                                                                 |
| 009 | [ci-shard-fanout](experiments/009-ci-shard-fanout)                       | How many CI shards pay for their own setup?                                  | Partial: k ≈ √(T/S); 5.8 ms here, so 15 shards went 14.3×; at 15 s setup, a 2.7 s suite never shards                             |
| 010 | [lockfile-resolution-cost](experiments/010-lockfile-resolution-cost)     | With a warm cache, how much of `bun install` is resolution?                  | Validated: 30 µs/pkg to link, lockfile still 38% faster with zero requests, cold cache 10.8× on a wide graph and 280× on a chain |
| 011 | [node-test-process-per-file](experiments/011-node-test-process-per-file) | What does a child process per test file cost `node --test`?                  | Invalidated: 80.7 ms/file, not 25–40; 19× in-process at 32 files, no crossover                                                   |
| 012 | [import-graph-depth](experiments/012-import-graph-depth)                 | Does a deep import chain cost start-up at the same module count?             | Partial: Bun 60 µs/level, 2.1× at depth 50; Node crashes at 765                                                                  |
| 013 | [git-status-index-scaling](experiments/013-git-status-index-scaling)     | What does `git status` cost a hook at 1k–100k tracked files?                 | Partial: 2.2 µs/file, 217 ms at 100k; `-uno` saves 13 %, `diff --cached` 17.5× cheaper                                           |
| 014 | [worker-thread-per-file](experiments/014-worker-thread-per-file)         | What does a fresh worker thread per test file cost against a forked process? | Validated: 21.5 ms/file vs 51; 3.9× cheaper than `node --test`, a reused pool 1.35 ms but leaks module state                     |
| 015 | [cache-archive-restore](experiments/015-cache-archive-restore)           | What does restoring a 20k-file cache tree cost as tar, tar.gz and tar.zst?   | Validated: 62.7 µs/file is 78 % of the restore; tar 1.60 s, zstd -1 1.69 s (−71 % bytes), gzip -6 2.63 s; `cp -a` 2.36 s         |

The backlog is in [IDEAS.md](IDEAS.md). How an experiment is run and written up is in [AGENTS.md](AGENTS.md).
